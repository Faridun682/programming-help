Урок 1. Что такое JavaScript?

JavaScript — это язык программирования, который делает сайты живыми: кнопки реагируют на нажатия, текст меняется, появляются меню, игры и анимации.

Запомни: HTML создаёт структуру сайта, CSS отвечает за дизайн, а JavaScript — за интерактивность. Именно JavaScript заставляет страницу «думать» и отвечать на действия человека.

1. Переменные

Переменная — это коробка с названием, в которой хранится значение. Её создают словом let или const: 

let age = 12;
const name = "Али";

let — значение потом можно менять.
const — значение менять нельзя.

2. Типы данных

Строка — текст в кавычках: "Привет".
Число — например, 25 или 3.14.
Логическое значение — true (правда) или false (ложь). 

let text = "Привет, мир!";
let count = 5;
let isStudent = true;

3. Вывод в консоль

Команда console.log() выводит значение в консоль браузера. Её удобно использовать, чтобы проверять, что делает код. Консоль открывается клавишей F12. 

console.log("Привет, мир!");
console.log(2 + 3);

4. Условия

Условие позволяет программе принимать решения: если что-то верно, выполняется один код, иначе — другой. 

let age = 12;

if (age >= 18) {
    console.log("Ты взрослый");
} else {
    console.log("Ты ещё школьник");
}

5. Функции

Функция — это набор команд с названием. Один раз её описываешь, а потом вызываешь сколько угодно раз. 

function sayHello(name) {
    console.log("Привет, " + name + "!");
}

sayHello("Али");
sayHello("Мария");

6. Работа со страницей

Самое интересное — JavaScript умеет менять содержимое страницы. Сначала мы находим элемент по его id, а потом реагируем на клик по нему: 

<h1 id="title">Привет!</h1>
<button id="btn">Нажми</button>

const title = document.getElementById("title");
const button = document.getElementById("btn");

button.addEventListener("click", function () {
    title.textContent = "Ты нажал на кнопку!";
});

getElementById — найти элемент по id.
addEventListener — «слушать» событие, например клик.
textContent — текст элемента, который можно изменить.
