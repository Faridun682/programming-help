Урок 1. Что такое HTML?

HTML — это язык разметки, который используется для создания структуры веб-страниц.

Запомни: HTML создаёт структуру сайта, CSS отвечает за дизайн, а JavaScript — за интерактивность.

1. Основные HTML-теги

Теги помогают браузеру понимать содержимое страницы.

<h1>Привет!</h1>
<p>Это мой первый сайт.</p>

h1 — заголовок.
p — обычный текст, то есть абзац.

2. Структура HTML-документа

Каждая HTML-страница обычно начинается с такой структуры:

<!DOCTYPE html>
<html lang="ru">
  <head>
    <meta charset="UTF-8">
    <title>Мой сайт</title>
  </head>
  <body>
    <h1>Привет!</h1>
  </body>
</html>

3. Для чего нужны основные теги?

<html> — начало HTML-документа.

<head> — информация о странице.

<title> — название страницы во вкладке браузера.

<body> — основное содержимое страницы.

<h1> — главный заголовок.

<p> — абзац текста.
