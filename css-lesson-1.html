Урок 1. Что такое CSS?

CSS — это язык стилей, который отвечает за внешний вид веб-страниц: цвета, шрифты, отступы, размеры и расположение элементов.

Запомни: HTML создаёт структуру сайта, CSS отвечает за дизайн, а JavaScript — за интерактивность. Без CSS любая страница выглядит как простой чёрный текст на белом фоне.

1. Как выглядит CSS-правило

CSS состоит из правил. Каждое правило говорит браузеру: «найди вот такие элементы и оформи их вот так». 

h1 {
    color: blue;
    font-size: 40px;
}

h1 — селектор: он указывает, к какому элементу применить стиль.
color — свойство: что именно мы меняем.
blue — значение: каким это должно стать.

Свойство и значение записываются через двоеточие, а в конце строки ставится точка с запятой. Все свойства правила находятся внутри фигурных скобок.

2. Как подключить CSS к странице

Самый простой способ — написать стили внутри тега <style> в разделе <head>: 

<head>
    <style>
        h1 {
            color: blue;
        }
    </style>
</head>

Когда сайт растёт, стили выносят в отдельный файл и подключают его так: 

<link rel="stylesheet" href="style.css">

3. Основные свойства

color — цвет текста.
background-color — цвет фона.
font-size — размер шрифта.
font-family — шрифт.
text-align — выравнивание текста (left, center, right). 

p {
    color: #475569;
    background-color: #f1f5f9;
    font-size: 20px;
    font-family: Arial, sans-serif;
    text-align: center;
}

Цвет можно писать по-разному: словом (red), кодом (#2563eb) или функцией (rgb(37, 99, 235)).

4. Отступы и рамки

У каждого элемента есть внутренний отступ padding (расстояние от текста до края блока), внешний отступ margin (расстояние до соседних элементов) и рамка border. 

.box {
    padding: 20px;
    margin: 15px;
    border: 2px solid #2563eb;
    border-radius: 10px;
}

Свойство border-radius скругляет углы блока.

5. Классы

Чтобы оформить не все элементы одного вида, а только некоторые, им дают класс. В HTML он пишется в атрибуте class, а в CSS перед названием ставится точка: 

<p class="important">Это важный текст</p>

.important {
    color: red;
    font-weight: bold;
}
